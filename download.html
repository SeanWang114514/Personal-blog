FAQ

下载前常见问题

下载速度很慢怎么办？

GitHub Releases 在国内访问不稳定。可以试试云盘页里的不限速渠道， 或者用代理后重新下载。

安装包为什么这么大？

因为这些工具都内置了本地模型（OCR、语音识别、词库）， 用体积换「离线可用、不联网、数据不出本机」。

需要管理员权限吗？

不需要。便携版解压即用；安装包写入的是用户目录，不碰系统目录， 卸载直接删文件夹即可。

更新怎么获取？

目前需要手动下载新版本覆盖。版本号与体积会同步更新在本页， 也可以 Watch 对应的 GitHub 仓库接收发布通知。
