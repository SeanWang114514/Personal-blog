# DeepSeek 海报展 · 52 种风格自我介绍

一个把同一条自我介绍渲染成 52 种经典视觉风格的海报墙网页。所有海报都由同一个 `PROFILE` 数据源生成，改一次内容，52 张海报同步更新。

## 功能

- 52 种海报风格：瑞士国际主义、包豪斯、赛博朋克、日式和风、蒸汽波、像素、代码矩阵等
- 点击任意海报放大查看，支持方向键切换、Esc 关闭
- 纯 HTML + CSS + JavaScript 单文件实现，零依赖、零构建
- 响应式网格布局，桌面和手机都能看

## 使用

直接用浏览器打开 `index.html` 即可。

如果想换成自己的信息，打开文件搜索 `PROFILE`，修改：

- `name`：名字
- `role`：头衔
- `intro`：一段自我介绍
- `tags`：标签列表
- `mail`：联系方式

## 部署到 GitHub Pages

1. 把仓库推送到 GitHub
2. 在仓库 Settings → Pages 中选择 `master` 分支
3. 访问 `https://<用户名>.github.io/<仓库名>/`

## 文件结构

- `index.html`：主页面（52 张海报）
- `_旧版备份/`：早期版本备份
- `article.md`：项目文章
