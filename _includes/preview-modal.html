{%- comment -%} 静态网站预览弹窗 -------------------------------------------------------------------------- 站点上的「网页工具」（海报展 / 天梯图 / 高星项目）本身就是可以打开的静态页面， 之前只能点「体验」跳走。这里给它们一个原地预览：点「预览」在当前页开一个 覆盖层，里面用 iframe 加载真实站点。 iframe 的 src 不写在 HTML 里，而是点开时才由 JS 赋上 —— 否则每次打开列表页 都会替你访问三个外部站点，既慢又不符合这个站「不产生第三方请求」的做法。 真正发起外部请求的时机，是你主动点了「预览」。 只能被 iframe 的前提是目标站没有 X-Frame-Options / CSP frame-ancestors， 这几个 GitHub Pages 站点都没有；万一将来加了，覆盖层里有「在新标签页打开」 作为兜底。 {%- endcomment -%}
